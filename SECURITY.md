# Política de seguridad

## Versiones mantenidas

Este proyecto se encuentra en desarrollo.

Las correcciones de seguridad se aplicarán a la versión más reciente
disponible en la rama `main`. No se garantiza el mantenimiento de
versiones anteriores.

## Comunicar una vulnerabilidad

Si detectas una posible vulnerabilidad, comunícala de forma privada
a través de este canal:

novanoticia@icloud.com

No publiques vulnerabilidades sin corregir en las incidencias
públicas (Issues), las discusiones ni los comentarios del repositorio.

En tu comunicación, incluye cuando sea posible:

- Una descripción del problema.
- El archivo o componente afectado.
- Los pasos necesarios para reproducirlo.
- Su posible impacto.
- Una propuesta de solución, si la tienes.

No incluyas contraseñas, claves de API, tokens ni datos personales.
Si necesitas aportar un ejemplo, utiliza datos ficticios.

## Revisión y corrección

Las comunicaciones se revisarán según la disponibilidad de las
personas responsables del proyecto. No se garantiza un plazo
concreto de respuesta o resolución.

Te pedimos que no publiques detalles que faciliten la explotación
del problema hasta que hayamos podido revisarlo y coordinar su
divulgación.

## Alcance

Esta política se refiere al código y los archivos de este repositorio.
Los problemas de servicios o dependencias de terceros deben
comunicarse también a sus responsables.
